## 三、阴影

**均为暖色调，不用中性黑。** 用黑色会让整个界面显脏。

| 令牌 | 值 |
|---|---|
| `--sh-card` | `0 2px 8px rgba(232,112,58,.10)` |
| `--sh-cta` | `0 8px 20px -4px rgba(232,112,58,.30)` |

画布外框另有一层中性投影（仅模拟机身浮起，不参与界面层次）：
`0 30px 70px -20px rgba(70,44,22,.38)` + 内描边 `0 0 0 1px rgba(255,255,255,.55)`。

## 四、字体

| 令牌 | 字体栈 | 用途 |
|---|---|---|
| `--font` | PingFang SC → HarmonyOS Sans SC → Microsoft YaHei UI → Microsoft YaHei → Source Han Sans SC → Noto Sans SC | 界面文字 |
| `--font-serif` | Source Han Serif CN → Source Han Serif SC → Noto Serif SC → Songti SC → STSong → SimSun | **菜名**（宋体带来「菜谱书」的质感） |

**规则**：菜名走衬线（`--font-serif`），其余所有文字走无衬线（`--font`）。两者不可混用。

## 五、页面骨架

固定画布 **390 × 844**（iPhone 14 逻辑分辨率），纵向三段式：

```
┌─────────────────────────┐
│ 状态栏      62px         │  时间左，信号 / WiFi / 电池右
├─────────────────────────┤
│ 内容区      flex:1       │  padding 20px，纵向滚动，隐藏滚动条
│            min-height:0  │  ← min-height 必须为 0，否则超长内容撑破容器
├─────────────────────────┤
│ 底部导航    胶囊 Tab      │  首页 / 菜谱 / 记录 / 我的
└─────────────────────────┘
```

- 屏幕切换：绝对定位铺满 + `display:none / flex` 切换，
  配 `pushIn`（右侧滑入）/ `popIn`（左侧滑入）两种动画，时长 `.24s`，缓动 `cubic-bezier(.32,.72,0,1)`。
- 窄屏（真机）：去掉画布圆角与投影，同色同底，转为全屏。桌面端保持画布形态并等比缩放居中。

## 六、图标

全部为**内联 SVG**，不使用 emoji、不使用图标字体。

- 统一画在 **24×24 坐标系**内，再用 `ic(size, inner)` 缩放到目标尺寸。
  这样同一图形换任何尺寸都不会被裁切。
- 状态栏图标例外：按设计稿保持非正方形比例
  （信号 18×12、WiFi 17×12、电池 25×12）。
- 默认描边宽 `1.8`，线性图标；`stroke-linecap: round`、`stroke-linejoin: round`。
- 底部导航图标渲染尺寸 18px。

## 七、组件规格

| 组件 | 规格 |
|---|---|
| 卡片 | 底色 `--card`，圆角 20px，描边 `--border`，阴影 `--sh-card` |
| 主按钮 | 底色 `--brand`，文字白色，圆角 16px，高 56px，阴影 `--sh-cta` |
| 胶囊标签 | 圆角 100px，高 34px，左右内距 14px，14px 字号 |
| 菜品图 | 圆角 16px，`object-fit: cover` |
| 筛选条 | 横向滚动，隐藏滚动条，选中态用主色浅底 + 主色文字 |
| Tab 栏 | 胶囊型容器，激活态用 `--ink`（不是主色） |

## 九、代码落地对照

设计令牌在 `app/index.html` 的 `:root`（第 12–50 行）中同名定义。
JS 侧另有一份 `C` 颜色常量（第 393 行）用于内联 SVG 的 `stroke` / `fill`，
因为 SVG 属性里不能直接用 CSS 变量。**改色时两处都要改。**
