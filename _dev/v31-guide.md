### 字段规则（会被脚本逐条校验，违反就报错）

| 字段 | 规则 |
|---|---|
| `id` | 只含小写字母、数字、连字符（`/^[a-z0-9-]+$/`）；**全库唯一**；用拼音 |
| `name` | 中文菜名，**全库唯一**（不能和任何分类已有菜重名，先跑清单确认） |
| `cat` | 必须精确等于 `'yuecai'` / `'chuancai'` / `'xiangcai'` 中的一个 |
| `time` | 整数分钟，1~480 |
| `diff` | 只能是 `'简单'` / `'中等'` / `'进阶'` |
| `kcal` | 整数，1~3000（按 2 人份估） |
| `tags` | 非空数组，**只用**：`快手` `下饭` `硬菜` `清淡` `少油` `低脂` `素食` `辣` `甜` `重口` `暖胃` `家常` `养生`，每道 2~4 个 |
| `ings` | ≥2 项，每项 `['食材名', '用量']`。**用量尽量以阿拉伯数字开头**（`'300 g'`、`'2 个'`），因为详情页会按人数等比换算；无法量化的用 `'适量'`、`'少许'`、`'几滴'` |
| `steps` | **5~7 步**，每步 `{ t, d }`，`t` 是 4~6 字小标题，`d` 见下 |

### `d` 的写法（这是本次重点：让小白照着能做成）

每一步都要写清 **怎么做 + 做到什么程度 + 为什么**。具体来说，尽量包含：

- **火候**：大火 / 中火 / 小火 / 油温几成（并给小白翻译，见下）
- **时间**：明确分钟数
- **判断标准**：怎么知道这一步做对了
- **常见坑**：这一步最容易翻车的地方

对比一下（左边是凑数的，右边是能用的）：

| ❌ 不算合格 | ✅ 合格 |
|---|---|
| 把肉炒熟 | 大火下锅快速滑散，肉片边缘变白、中间还带一点粉就立刻盛出，余温会继续把它焖熟，久炒就柴了 |
| 加调料翻炒 | 沿着锅边淋 1 汤匙料酒（锅边温度高，酒香会瞬间爆出来），再下 2 汤匙生抽翻匀 |
| 煮至入味 | 中小火焖 8 分钟，汤汁收到原来的一半、能用铲子划开锅底看见锅底就对了 |

**专业术语要给小白翻译**（这一步很关键）：

- 「油温七成热」→ 筷子插进油里周围冒小泡；油面冒青烟就是九成以上，已经过头了
- 「焯水断生」→ 水开后下锅，叶子变深绿就捞，大约 30 秒
- 「收汁挂勺」→ 铲子舀起汤汁再倒回去，汁能薄薄挂在铲背上、不是哗一下流走

### 写作要求（**这是本次交付的核心，请认真写**）

**`pick`：3~6 条，只写主要食材和关键调料**（`盐`、`水`、`油` 这种不用写）。
每一条必须给出**能上手判断的具体特征** —— 看什么颜色、摸什么手感、闻什么味、看包装上哪个标注。

| ❌ 废话 | ✅ 能用 |
|---|---|
| 选购新鲜的猪肉 | 五花肉挑三层肥两层瘦、层数分明的；手指按下去能弹回来，表面发黏或渗水的不要 |
| 挑选优质的干辣椒 | 干辣椒捏起来干脆、掰开有浓辣椒香，发软或发霉的不要；做辣子鸡选二荆条，香而不死辣 |
| 选择好的豆腐 | 嫩豆腐（内酯）盒装挑日期最新的，摇一摇不晃荡说明没散；老豆腐选表面微湿、按下去有弹性的 |
| 买新鲜的鱼 | 鲈鱼看眼睛：清澈凸起、不发浑；掀开鳃盖是鲜红色，按鱼身能弹回来 |

**`tips`：2~4 条**，优先写这两类（按价值排序）：

1. **把术语翻译成小白能判断的标准** —— 这是最有价值的一类
   - 「七成热」→ 筷子插进油里周围冒小泡；冒青烟就过头了
   - 「断生」→ 水开后下锅，颜色一变深就捞，大约 30 秒
   - 「大火收汁」→ 汤汁从能漫过食材收到只剩锅底一层，铲子划过去能看见锅底
2. **新手最容易翻车的地方**，说清"为什么"和"怎么避免"
   - 豆腐下锅前用淡盐水泡 5 分钟，烧的时候就不容易碎
   - 炒糖色全程小火，糖化开变成琥珀色就马上下肉，再等 3 秒就发苦
   - 腌肉时最后才加淀粉抓匀，顺序反了肉会出水变柴

**禁止**：写「注意火候」「掌握时间」「根据个人口味调整」这类空话 —— 一条都不要。
